# UWT Trail Finder

A trail finder for UW Tacoma students. Pick how far you're willing to go, how hard a hike you want, and whether you need to get there by bus, and it shows trails near campus that fit.

Built by Saeed Esparza and Vaughn DeTray for TCSS 490, Artifact 4 ("For Someone Else").
